HEART DISEASE PREDICTOR
Project Overview
This project is a Machine Learning-based web application which is built using flask that predicts the risk of heart disease using clinical patient data taken from dataset available on keggle. It is built using Python (Flask is used) for the backend, Machine Learning models like Scikit-learn for the model, and other languages HTML/CSS/JavaScript for the frontend UI.
The system allows users to enter medical parameters and to receive an instant prediction of whether they are at low or high risk of heart disease or have chances of heartattack.

Objective
The main objectives of this project is:
•	To predict heart disease risk using old (keggle)patient data
•	Provide an user-friendly web interface

 Technologies Used
The technologies used in this project are:
Backend:
•	Python
•	Flask 
Machine Learning (Models):
•	Scikit-learn
•	Pandas
•	NumPy
•	StandardScaler (feature scaling)
Frontend(languages):
•	HTML5
•	CSS3
•	JavaScript (for slider interactions)

 Input taken from Dataset from keggle Features (13 Features):
1.	Age
2.	Sex
3.	Chest Pain Type (cp)
4.	Resting Blood Pressure (trestbps)
5.	Cholesterol (chol)
6.	Fasting Blood Sugar (fbs)
7.	Resting ECG (restecg)
8.	Maximum Heart Rate (thalach)
9.	Exercise Induced Angina (exang)
10.	Oldpeak (ST depression)
11.	Slope of peak exercise ST segment
12.	Number of major vessels (ca)
13.	Thalassemia (thal)
 Project Workflow
1. Data Collection
A heart disease dataset (CSV format) downloaded from keggle is used for training the model.
2. Data Preprocessing
•	Handling Missing values
•	Features separated like (X and y)
•	Data scaled using StandardScaler
3. Model Training
•	Logistic Regression model is trained
•	Accuracy is evaluated
4. Model Saving
The models are saved from collab Google
•	Model saved as model.pkl
•	Scaler saved as scaler.pkl
5. Web Application
•	Flask for backend routes
•	HTML do collects user input
•	Prediction is displayed on result page built using flask

 Web App Features
•	User-friendly medical dashboard UI
•	Slider-based input for better usability and keep values in range
•	Instant prediction after clicking output
